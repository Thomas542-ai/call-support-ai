# Aria Support Line — build roadmap

Built feature by feature; each phase must work before the next starts.

## Done — Phase 1: Accounts + live AI voice call
- [x] Email/password + Google sign-in, profiles, roles (customer / agent / admin) with RLS
- [x] In-browser voice call: mic capture with silence detection, transcription, AI reply, spoken answer
- [x] Interruptions (barge-in) and full in-call context
- [x] Live transcript, call records and per-call transcript history

## Next phases (not started)
- [ ] Phase 2: Advanced call summary generated at the end of each call
- [ ] Phase 3: Conversation memory graph — recognise returning customers, continue unresolved issues
- [ ] Phase 4: Real-time intent prediction engine (intent, urgency, sentiment, confidence)
- [ ] Phase 5: Autonomous resolution planner with permissions, validation and audit trail
- [ ] Phase 6: Intelligent human handoff + real-time representative interface
- [ ] Phase 7: Business data/tool integration layer with a standardised tool interface
- [ ] Phase 8: Automated follow-up tasks, reminders and tickets
- [ ] Phase 9: Administrator dashboard (active calls, customers, action history, escalations)
- [ ] Phase 10: AI support analytics with filters and visual dashboards
- [ ] Phase 11: Multi-agent configuration (personality, tools, hours, escalation rules)
- [ ] Phase 12: Knowledge base with versioning and retrieval during calls
- [ ] Phase 13: Security hardening, audit logs, retention/deletion policies
- [ ] Phase 14: Reliability/fallback behaviour and automated test suite
